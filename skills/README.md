# skills

Skills live in [gabchess/skills](https://github.com/gabchess/skills), grouped by outcome. Add new ones there.

To install them, run `npx skills@latest add gabchess/skills`, or clone it and run `npm run link`.

This repo keeps only the template every skill starts from: [`templates/skill/`](../templates/skill/). CI in gabchess/skills fails when its copy drifts from this one.
