# ADR template

Copy `0000-title.md` to `decisions/NNNN-<short-title>.md` with the next free number. CI fails on an ADR that is not numbered, that loses a section the template has, or that runs past 60 lines.

Add these sections only when they help:

- "Considered options": each rejected option and why it lost.
- "Consequences": what changes for the people and agents who follow it.
- "Status": "Superseded by NNNN" when a later ADR replaces it. Never delete an ADR.
