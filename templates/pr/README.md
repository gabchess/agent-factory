# PR body block

Copy `what-it-can-break.md` into every PR body, in any repo, and fill each field. A reviewer reads it to know where to look.

## The bar

- Fill all five fields. Name the real paths, skills, agents and repos, never "various files".
- Write Before and After as what an agent or user does, not as what the diff edits.
- In Can break, give each risk with the sign someone would see. Write "nothing found" only next to what you checked, such as the other steps of a skill you changed or the callers of a function.
- Keep the block under 12 lines. Link longer evidence from it.
