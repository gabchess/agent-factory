# data

Generated files and run records. Add run records; never edit them.

- `runs.jsonl`: the run record, one row per attempt, appended by the `orchestrate-task` gate script in gabchess/skills. The `run-records` check fails a malformed row.
- `instructions.snapshot`: what an agent loads in this repo, generated by `npm run snapshot`. Never edit it by hand.
- `audit/old-sources.tsv`: the verdict on every Markdown file in gabchess/agent-rules at 562fe19 and gabchess/vault-agentops at 137b4c6, and on every ticket in the old AgentOps Linear project. A rewrite names the ticket that rewrites it. `checks/audit-verdicts.js` checks its shape.
- `loading-receipts/`: one loading receipt per harness, written by the [loading-probe skill](https://github.com/gabchess/skills/blob/main/skills/quality/loading-probe/SKILL.md) in gabchess/skills. `loaded` says which fixture instructions and skills reached the model during the run, at startup or on demand; `evidence` and `note` say which. A skill that loads on demand is not in the starting context. `followed` says whether the delivered file kept the planted rule, or `"not run"`. Before you rely on a harness loading `AGENTS.md` or a skill, check its receipt matches the version you run; re-run the probe when it does not.
