# data

Generated files and run records. Add run records; never edit them.

- `runs.jsonl`: the run record, one row per attempt, appended by the `orchestrate-task` gate script in gabchess/skills. The `run-records` check fails a malformed row.
- `instructions.snapshot`: what an agent loads in this repo, generated by `npm run snapshot`. Never edit it by hand.
- `audit/old-sources.tsv`: the verdict on every Markdown file in gabchess/agent-rules at 562fe19 and gabchess/vault-agentops at 137b4c6, and on every ticket in the old AgentOps Linear project. A rewrite names the ticket that rewrites it. `checks/audit-verdicts.js` checks its shape.
