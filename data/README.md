# data

Generated files and run records. Add run records; never edit them.

- `instructions.snapshot`: what an agent loads in this repo, generated by `npm run snapshot`. Never edit it by hand.
- `loading-receipts/`: one loading receipt per harness, written by the [loading-probe skill](https://github.com/gabchess/skills/blob/main/skills/quality/loading-probe/SKILL.md) in gabchess/skills. `loaded` says which fixture instructions and skills reached the model; `followed` says whether the delivered file kept the planted rule, or `"not run"`. Before you rely on a harness loading `AGENTS.md` or a skill, check its receipt matches the version you run; re-run the probe when it does not.
