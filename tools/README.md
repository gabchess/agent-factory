# tools

One contract per MCP server: purpose, which agents may use it, and access. Nothing here installs a server; install it through your harness, then use it as its contract allows.

- To see whether a tool exists, check the harness's live tool list, never a config file. When it is not there, say "not found", never "does not exist".
- Read x.com and pages behind a login through Gabriel's logged-in browser with the harness's browser tool. A plain fetch gets HTTP 402 on x.com.
